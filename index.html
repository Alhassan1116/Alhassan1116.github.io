NBA Flow — Real-Time Analytics

sourceNBA API Kafka Druid serveGrafana
Batch
sourceNBA API Airflow MinIO · S3 Druid serveGrafana

A Lambda-style pipeline over live NBA data. The speed layer streams game scores from the NBA API through Apache Kafka into Apache Druid for sub-second OLAP in Grafana. In parallel, a batch layer orchestrated by Apache Airflow pulls from the NBA API into MinIO (S3) and loads Druid for historical analysis. Both layers converge in Grafana — the full stack containerized with Docker Compose.
